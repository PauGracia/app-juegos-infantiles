Cómo jugar

Modo normal

- Selecciona el nivel de dificultad.
- Indica el número de operaciones que quieres resolver.
- Introduce tus respuestas y pulsa "Comprobar".
- Al finalizar verás un resumen de aciertos y errores.

Modo desafío

- Se resolverán niveles consecutivos con tiempo límite.
- Cada nivel tiene un número de operaciones distinto y operadores variados.
- Si completas todas las operaciones antes del tiempo, pasarás al siguiente nivel.
- Si se acaba el tiempo, deberás reiniciar el desafío.
